
# Recommendations Object

*This model accepts additional fields of type unknown.*

## Structure

`RecommendationsObject`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `seeds` | [`RecommendationSeedObject[]`](../../doc/models/recommendation-seed-object.md) | Required | An array of recommendation seed objects. |
| `tracks` | [`TrackObject[]`](../../doc/models/track-object.md) | Required | An array of track objects ordered according to the parameters supplied. |
| `additionalProperties` | `Record<string, unknown>` | Optional | - |
